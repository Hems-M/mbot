Pick your robot

Each robot has two parts: Hardware (build it) and Software (set it up). Not sure which robot you have? The Classic has two wheels. The Omni has three.

MBot Classic

Two wheels, Raspberry Pi 5. Uses the server setup: no desktop, you work from your laptop over SSH.

How it works

Follow the steps in order. Each page tells you what you need and what you should see when it works.

  1. BuildPut the robot together, plate by plate.
  2. Set upFlash the SD card, start the robot and join Wi-Fi.
  3. CalibrateTeach the control board your motors and load the firmware.
  4. Drive and codeTest drive in the browser, then write your own programs.
