**Setting up a new robot?** Follow the [Setup Guide](/docs/setup/) first. It walks through the connection and driving tutorials below in order.
{: .notice--info}

## Everyday tasks

* [What's my MBot's IP?](/docs/tutorials/get-ip/): Find the robot's IP address from its display, the IP registry, or the SD card.
* [Drive your MBot](/docs/tutorials/drive/): Drive the robot from the web app. A quick way to check the hardware works.
* [Flashing Firmware](/docs/setup/firmware/): Put new firmware on the MBot Control Board.

## Connecting to the robot

* [Connecting with VSCode](/docs/tutorials/vscode/): The main way to program the robot from your laptop.
* [Connecting with NoMachine](/docs/tutorials/no-machine/): Use the Raspberry Pi's desktop from your laptop.

## Programming

* [The MBot Bridge API](/docs/tutorials/bridge/): Program the robot with the MBot Bridge.
* [MicroPython](/docs/tutorials/micropython/): Program the MBot using MicroPython.

## Mapping and tools

* [Mapping & Localization](/docs/tutorials/mapping/): Build a map of your environment using SLAM.
* [MBot Command Line Tool](/docs/tutorials/mbot-cli-tool/): Monitor LCM traffic and manage MBot services from the terminal.
