MBot website: offline copy
==========================

VERSION.txt in this folder says which branch and commit this copy is.

You need Python 3 (already on most Macs and Linux machines;
Windows: https://www.python.org/downloads/).

Mac / Linux
  1. Open Terminal in this folder.
  2. Run:  bash serve.sh
  3. Your browser opens the site. The terminal prints the address
     and which version it is.

Windows
  1. Double-click serve.bat

Viewing more than one version? Each copy picks its own free port
(4000, 4001, ...), so two copies never get mixed up. Stop a copy
with Ctrl+C (or close its window on Windows).

Do not open index.html by double-clicking it. The pages use links
that start with "/", which only work through the local server.
Search needs the local server too.
